# 재무 파서 비교 검증 기록

룰베이스 파서와 AI 파서를 비교할 때 사용한 정답의 출처, 채점 방식과 검증 한계를 정리한 문서 전용 저장소입니다.

## 문서

- [정답셋의 구성과 검증 범위](docs/parser-comparison-ground-truth.md)

## 확인된 범위

- 대상: 기본 조직 Excel 17개와 전체 마스터 1개
- 정답: 더미 생성 당시 manifest에 저장한 월별·연간 재무 합계
- 지표: 금액 집계 일치율. 셀별 조직·항목·기간의 의미 정확도와 구분
- AI 실행: 대화 모델이 만든 구조 해석 계획을 기존 AI 파서에서 재생
- 미검증: 독립적인 셀별 의미 정확도, 실제 모델 API의 전체 실행 성능, DB 적재 성공률

파서 코드, 원본 Excel, API 키 및 실행 산출물은 포함하지 않습니다. 문서 안의 근거 경로는 원래 검증 프로젝트의 작업 폴더 기준입니다.

기준 확인일: 2026-11-12
